# Healthcare Patient Records SQL Analysis

##  Project Overview

* This project focuses on analyzing healthcare patient records using SQL.
* The dataset contains patient demographics, medical conditions, health metrics, and treatment information.
* The main objective is to practice SQL queries on a real-world healthcare-style dataset.
* The analysis helps identify patterns related to diseases, patients, treatment costs, and hospital stays.

##  Objectives

* Analyze patient demographic information.
* Identify the distribution of different diseases.
* Analyze patients based on gender and age.
* Study blood pressure and cholesterol levels.
* Analyze BMI and smoking status.
* Calculate treatment costs and compare healthcare expenses.
* Analyze admission and discharge dates.
* Calculate patient hospital stay duration.
* Generate meaningful healthcare insights using SQL.

##  Dataset Information

* The project uses a PatientRecords table.
* The table contains patient identification and medical information.
* Key columns include PatientID, PatientName, Gender, Age, City, and Disease.
* It also contains BloodPressure, Cholesterol, and BMI measurements.
* SmokingStatus is included to analyze lifestyle-related patterns.
* TreatmentCost is used to analyze healthcare expenses.
* AdmissionDate and DischargeDate are used for hospitalization analysis.

##  Analysis Performed

* The project analyzes the number of patients across different diseases.
* It examines patient distribution across different cities.
* Age-based patient analysis is performed to understand demographic patterns.
* Gender-wise patient distribution is also analyzed.
* Blood pressure and cholesterol values are examined.
* BMI values are analyzed across patients and medical conditions.
* Smoking and non-smoking patient groups are compared.
* Treatment costs are analyzed to identify healthcare expenditure patterns.
* Hospital admission and discharge dates are used to calculate length of stay.
